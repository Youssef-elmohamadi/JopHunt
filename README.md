## 💻 1. المتطلبات الأساسية (Prerequisites)

- **نظام التشغيل:** Windows 10 أو 11 (أو سيرفر Linux/VPS).
- **بايثون:** Python 3.10 أو أحدث (يُفضل 3.11 أو 3.12).
  > **تنبيه مهم أثناء تثبيت بايثون:** تأكد من تفعيل علامة الصح بجانب:  
  > `[✔] Add Python to PATH`
- **متصفح Google Chrome:** مثبت على جهازك بشكل طبيعي.
- **حساب تيليجرام:** هاتف شخصي لتلقي الإشعارات والموافقة على العروض.

## 🛠️ 2. التثبيت والإعداد لأول مرة (Step-by-Step Installation)

افتح موجه الأوامر **PowerShell** أو **CMD** داخل مجلد المشروع `W:\Atrees` ونفّذ الخطوات التالية:

### خطوة 1: إنشاء البيئة الافتراضية (Virtual Environment)
```powershell
python -m venv .venv
```

### خطوة 2: تفعيل البيئة الافتراضية
- على Windows PowerShell:
  ```powershell
  .\.venv\Scripts\Activate.ps1
  ```
  *(إذا ظهرت مشكلة في صلاحيات السكربتات، شغّل: `Set-ExecutionPolicy -ExecutionPolicy RemoteSigned -Scope CurrentUser`)*
- على Windows CMD:
  ```cmd
  .\.venv\Scripts\activate.bat
  ```

### خطوة 3: تثبيت كافة المكاتب والتبعيات
```powershell
pip install --upgrade pip
pip install -r requirements.txt
```

### خطوة 4: تثبيت متصفح Playwright (لتشغيل متصفح التقديم التلقائي)
```powershell
playwright install chromium
```

## 🔑 3. استخراج المفاتيح المطلوبة (.env Setup)

انسخ ملف القالب `.env.example` وأعد تسميته إلى `.env`:
```powershell
copy .env.example .env
```

افتح ملف `.env` واملأ البيانات التالية:

```ini
# ========================================================
# 1. إعدادات حساب التيليجرام لرصد القنوات (Telethon Userbot)
# ========================================================
# احصل عليهم مجاناً من https://my.telegram.org (تحت API Development Tools)
TG_API_ID=12345678
TG_API_HASH=abcdef0123456789abcdef0123456789
TG_SESSION_NAME=atrees_userbot

# يوزرات القنوات المستهدفة للرصد مفصولة بفواصل
TARGET_CHANNELS=@nafezly,@KhamsatRequests,@MostaqlDevelopment

# ========================================================
# 2. مفاتيح الذكاء الاصطناعي (مجانية 100% مع Failover تلقائي)
# ========================================================
# مفتاح Google Gemini من https://aistudio.google.com/app/apikey
GEMINI_API_KEY=AIzaSy...
GEMINI_MODEL=gemini-3.1-flash-lite

# مفتاح Groq الاحتياطي السريع من https://console.groq.com/keys
GROQ_API_KEY=gsk_...
GROQ_MODEL=openai/gpt-oss-120b

# ========================================================
# 3. إعدادات بوت التنبيهات والموافقات (HunterBot)
# ========================================================
# توكن البوت الذي أنشأته من @BotFather على تيليجرام
BOT_TOKEN=1234567890:ABCdef...
# معرف حسابك الشخصي (احصل عليه بمراسلة بوت @userinfobot)
MY_CHAT_ID=6745928157

# ========================================================
# 4. إعدادات المتصفح والتقديم التلقائي
# ========================================================
# false = يظهر متصفح Chrome أمامك أثناء ملء العرض وتقديمه
# true = يعمل المتصفح في الخلفية تماماً بصمت
BROWSER_HEADLESS=false
AUTO_SUBMIT_CONFIRM=false
```

## 🔐 4. تسجيل الدخول لمنصات العمل الحر (One-Time Setup)

> 💡 **ملاحظة أمان هامة:** البوت لا يخزن كلمات سرك نهائياً! بل يتم فتح متصفح Chrome حقيقي معتمَد بوضع التخفي، تقوم بتسجيل الدخول في حساباتك **لمرة واحدة فقط**، وتُحفظ الجلسة والكوكيز محلياً في مجلد `browser_session`.

### كيف تسجل الدخول؟ (اختر أحد الخيارين):
- **الخيار أ (بنقرة واحدة):** انقر مرتين على الملف الجاهز:  
  👉 **`Login_Platforms.bat`**
- **الخيار ب (من سطر الأوامر):**
  ```powershell
  .\.venv\Scripts\python.exe setup_session.py
  ```
- **الخيار ج:** من زر **"فتح المتصفح لتسجيل الدخول"** الموجود في لوحة التحكم (الداشبورد).

**ماذا تفعل في النافذة التي ستفتح؟**
1. سيفتح لك متصفح Chrome صفحات تسجيل الدخول لمنصات:
   - **مستقل** (`https://mostaql.com/login`)
   - **نفذلي** (`https://nafezly.com/login`)
   - **خمسات** (`https://khamsat.com`)
2. سجّل دخولك بحسابك الطبيعي (بالبريد، كلمة المرور، حساب Google، أو رمز 2FA).
3. بعد الانتهاء وتأكدك من فتح لوحات التحكم لحساباتك، ارجع للنافذة واضغط `[Enter]`.
4. مبروك! أصبح البوت مسجلاً ومخوّلاً لتقديم العروض باسمك دائماً.

## 🚀 5. طرق تشغيل النظام (How to Run)

اختر الطريقة التي تفضلها للتشغيل:

### الطريقة 1: التشغيل عبر لوحة التحكم (الخيار الموصى به للمبتدئين) ⭐
انقر مرتين على الملف:
```cmd
Start_Dashboard.bat
```
- سيتم تشغيل السيرفر المحلي فوراً وفتح المتصفح تلقائياً على: `http://localhost:8000`.
- يمكنك التحكم في البوت وتشغيله وإيقافه بضغطة زر وتعديل مفاتيحك وملفك الشخصي ومتابعة السجلات الحية.

---

### الطريقة 2: التشغيل المباشر من سطر الأوامر / الباتش (Direct Bot)
انقر مرتين على الملف:
```cmd
start_atrees.bat
```
أو عبر الأمر:
```powershell
.\.venv\Scripts\python.exe listener.py
```
- سيبدأ فوراً بالاتصال بحسابك في تيليجرام والإنصات للقنوات المستهدفة وبدء بوت الموافقات.
- لإيقاف البوت في أي وقت: انقر على **`stop_atrees.bat`** أو اضغط `Ctrl + C`.

---

### الطريقة 3: التشغيل الصامت في الخلفية (Silent Background)
إذا أردت تشغيل البوت في الخلفية دون بقاء أي شاشة سوداء مفتوحة:
- انقر مرتين على: **`run_silent.vbs`**
- لإيقافه: انقر مرتين على: **`stop_atrees.bat`**

## 📱 6. لوحة التحكم المحلية (Web Dashboard)

لوحة تحكم خفيفة وسريعة جداً مبنية بـ **FastAPI** و **Tailwind CSS**:

### فتح الداشبورد على نفس الكمبيوتر:
👉 **[http://localhost:8000](http://localhost:8000)**

### فتح الداشبورد على هاتفك المحمول (بنفس شبكة الواي فاي):
1. تأكد أن الموبايل متصل بنفس شبكة الـ Wi-Fi المنزلية للكمبيوتر.
2. افتح متصفح هاتفك واكتب عنوان الـ IP الخاص بجهازك متبوعاً بـ `:8000`:
   👉 **`http://192.168.1.60:8000`**
3. ستفتح لوحة التحكم كاملة على الموبايل لتشغيل/إيقاف البوت وتعديل إعداداتك ومتابعة السجلات لحظة بلحظة.

### مميزات الداشبورد:
- **لوحة التحكم والتيرمينال الحي:** زر تشغيل وإيقاف ضخم، مؤشر حالة نابض، ومستعرض سجلات (Logs) حي يلون الأخطاء والتحذيرات مع التمرير التلقائي.
- **إدارة الملف المهني (Profile):** تعديل الاسم، المسمى الوظيفي، المهارات والتقنيات، ونبرة صياغة العروض.
- **إدارة المفاتيح (.env):** تعديل توكن التيليجرام ومفاتيح الذكاء الاصطناعي دون فتح أي ملف نصي.
- **زر تسجيل دخول المنصات بنقرة واحدة.**

## 🤖 7. كيفية استخدام البوت على تيليجرام (Telegram Bot Workflow)

بمجرد تشغيل النظام، يعمل البوت بصورة آلية متكاملة:

1. **الرصد:** يستمع البوت للقنوات المحددة.
2. **الفلترة والتحليل:** فور نشر مشروع جديد، يقوم البوت بسحب التفاصيل كاملة من المنصة وتحليلها بواسطة الذكاء الاصطناعي (Gemini / Groq):
   - إذا كان المشروع خارج تخصص الويب (تصميم جرافيك، ترجمة، تطبيقات أصلية) يتم تجاهله وتسجيل السبب في السجلات.
   - إذا كان مطابقاً لمهاراتك، يتم استخراج المدة والسعر المقترحين، وصياغة عرض احترافي مقنع وموجز (50-90 كلمة بدون كليشيهات ذكاء اصطناعي وينتهي بسؤال تقني ذكي).
3. **بطاقة الموافقة الفورية:** يرسل لك البوت على تيليجرام رسالة بها:
   - رابط المشروع وملخصه.
   - **بيانات التقديم التلقائي:** السعر والمدة بدقة.
   - نص العرض المقترح.
   - زر **`✅ قدّم`** وزر **`❌ تخطي`**.
4. **التقديم:** 
   - بمجرد الضغط على **`✅ قدّم`**، يفتح المتصفح تلقائياً ويملأ الحقول ويضغط على زر الإرسال.
   - يلتقط صورة شاشة (Screenshot) قبل وبعد التقديم، ويرسل لك تأكيد نجاح التقديم مع الصورة على تيليجرام.
5. **التعديل السريع قبل الإرسال:**
   - إذا أردت تعديل العرض قبل إرساله، فقط اعمل **Reply (رد)** على رسالة البوت بنصك المعدل، وسيتم تحديثه فوراً قبل الضغط على "قدّم".
6. **تجربة أي مشروع يدوي:**
   - يمكنك في أي وقت نسخ رابط أي مشروع من مستقل أو نفذلي وإرساله مباشرة للبوت في شات التيليجرام وسيقوم البوت بتحليله فوراً وتجهيز العرض والتقديم عليه!

## ❓ 9. استكشاف الأخطاء وحلها (Troubleshooting & FAQs)

### س: تظهر رسالة `TelegramConflictError: Conflict: terminated by other getUpdates request`؟
- **السبب:** وجود أكثر من نافذة أو سكريبت يعمل بنفس توكن البوت في وقت واحد.
- **الحل:** قمنا ببرمجة النظام ليقوم تلقائياً بإنهاء أي عملية قديمة لـ `listener.py` عند بدء التشغيل لمنع أي تعارض. يمكنك أيضاً إيقاف كل العمليات يدوياً بنقر **`stop_atrees.bat`**.

### س: يظهر خطأ `429 RESOURCE_EXHAUSTED` في Gemini؟
- **الحل:** تم حل ذلك جذرياً؛ يحتوي النظام على سلسلة فشل تلقائية (Failover Chain): إذا استنفد نموذج Gemini حصته أو واجه ضغطاً، ينتقل تلقائياً لنماذج Flash Lite، ثم ينتقل مباشرة لمحرك **Groq API** فائق السرعة لضمان استمرار العمل مجاناً وبدون انقطاع.

### س: هل يمكن تشغيل البوت بدون ظهور نافذة المتصفح؟
- **نعم:** افتح لوحة التحكم أو ملف `.env` واجعل:
  ```ini
  BROWSER_HEADLESS=true
  ```
  وسيعمل المتصفح ويقدم العروض في الخلفية تماماً بصمت.

### س: كيف أضيف قنوات تيليجرام جديدة للرصد؟
- افتح لوحة التحكم أو ملف `.env` وأضف يوزر القناة في خانة `TARGET_CHANNELS` مفصولاً بفاصلة، مثال:
  ```ini
  TARGET_CHANNELS=@nafezly,@KhamsatRequests,@MostaqlDevelopment,@NewChannel
  ```
